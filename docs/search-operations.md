## Deployment and rollback

1. Review the diff; keep DATABASE_URL, IP_HASH_SALT, Telegram variables and pre-deploy migration unchanged. This SEO update makes no database/API changes.
2. Run npm ci, npm run build, npm run typecheck, npm run lint and npm run format:check. Python 3 is needed only for the SEO checker, not the application build.
3. Start the production build and run npm run seo:check -- --base http://localhost:3000. It validates raw HTML without executing JavaScript, XML sitemap coverage, canonical/social metadata, headings, JSON-LD, crawlable links/fragments, image/CSS/JS availability, API noindex and real 404 behavior. It never submits an application.
4. Deploy the reviewed commit through the existing Railway GitHub source on main. SITE_URL=https://melbetagents.org; SITE_NOINDEX must be unset or false. Keep normal npm run build and npm start.
5. Wait for Railway deployment success and health checks; run npm run seo:check -- --base https://melbetagents.org. Check homepage, application form, FAQ, guide and legal navigation on desktop/mobile.
6. Verify robots.txt, sitemap.xml, API X-Robots-Tag, HTTPS and redirects. www.melbetagents.org had no DNS answer during the initial audit: add it to Railway custom domains, then add the exact CNAME Railway supplies in DNS and verify TLS before testing the www redirect. Do not guess the target.
7. If verification fails, use Railway's prior successful deployment/rollback. No database rollback is needed for this SEO update.
